## 🎓 Diplomas Covered

The materials in this repository support the three core diplomas offered by Aptech Computer Education:

1. **CPISM** — *Certificate of Proficiency in Information System Management*
2. **DISM** — *Diploma in Information System Management*
3. **ADSE** — *Advanced Diploma in Software Engineering (ACCP)*

## 🚀 Recommended Study Pathway

1. **Read & Understand:** Review the textbook chapters and slide presentations in this repository for foundational theory.
2. **Review Past Papers:** Inspect past examination questions in [aptech-exam](https://github.com/HeshamGit/aptech-exam) to understand exam patterns and verified keys.
3. **Simulate Real Exams:** Launch the [AptechExam Web Portal](https://heshamgit.github.io/AptechExam/) or open the [Android App](https://github.com/HeshamGit/AptechExam) to take timed 45-minute tests under real examination conditions.
